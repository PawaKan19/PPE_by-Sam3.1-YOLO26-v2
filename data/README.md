# data — Raw Data and SAM Outputs

Stores raw image data and annotations generated by SAM 3.1 (used as ground truth for training YOLO26)

## Structure

```text
data/
├── raw/                        # Raw images from camera/CCTV (SAM input)
│   ├── blurred/                # Blurred images (robustness test)
│   └── custom_capture/         # Custom captured images
├── sam_outputs_ground_truth/   # SAM outputs (COCO + viz + experiments)
│   ├── blurred/
│   ├── custom_capture/
│   ├── coco/                   # Combined COCO
│   └── viz/                    # Combined visualization
└── processed/                  # Processed dataset (historical — v1 only)
    └── combined_coco_dataset_version_1/
        ├── images/
        └── annotations.json
```

> **Note**: The current production dataset is v3, stored at `yolo26_ppe/data/combined_coco_dataset_version_3/`. The `processed/` folder here contains only the historical v1 dataset.

## Data Flow

```text
data/raw/<batch>/
        │
        │  SAM 3.1 (sam3_auto_label/src/batch_segment.py)
        ▼
data/sam_outputs_ground_truth/<batch>/
    ├── coco/
    │   └── <image>.json        # COCO per-image (internal cache)
    ├── experiments/
    │   ├── experiments.db      # SQLite tracking
    │   └── <run_id>.json       # JSON artifacts
    └── viz/
        └── <image>.jpg         # overlay visualization
        │
        │  prepare dataset (yolo26_ppe/scripts/pipeline/01_prepare_dataset.py)
        ▼
yolo26_ppe/data/                # YOLO format dataset
```

## raw/

Each subfolder = 1 batch of raw images. The folder name is the batch name used in the CLI:

```bash
./auto_label.sh --sam --batch blurred
```

Supported file types: `.jpg`, `.jpeg`, `.png`, `.bmp`, `.webp`, `.tiff`, `.tif` (case-insensitive)

## sam_outputs_ground_truth/

Subfolder structure mirrors `raw/` — each batch contains:

- `coco/` — Per-image COCO JSON (internal cache for checkpoint/resume)
- `experiments/` — SQLite + JSON tracking
- `viz/` — Overlay images showing annotations

## processed/

Combined and processed datasets. The historical `combined_coco_dataset_version_1` (6 classes) is retained here. The current production dataset is v3 (4 classes), stored at `yolo26_ppe/data/combined_coco_dataset_version_3/`.

## Notes

- This folder stores large data — check `.gitignore` before committing
- Do not delete `sam_outputs_ground_truth/` if you plan to continue training YOLO, as it serves as ground truth
- If re-running SAM on an existing batch, use `--fresh` to clear checkpoints first; otherwise it will resume from the previous run
- Paths in config are WSL2 absolute paths (`/mnt/e/...`) — override with `--input`/`--output` when running elsewhere
